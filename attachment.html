Step-by-Step Workflow

How Does the Attachment Module Work?

The module follows a simple process that lets users store and manage important files without searching through separate folders.

01

Open Attachment Management

Open the application dashboard, select the module from the sidebar, and open its list page.

  • Open the Attachments page to view saved attachment groups
  • Use the Upload Attachment option to add a new record
02

Enter an Attachment Label

Give the attachment a clear name so it can be recognized later.

  • Enter a clear label, such as “Truck Insurance Documents”
  • Or use a label such as “October Office Bills”
  • The label helps users recognize the files later
03

Select One or More Files

Choose the documents you want to store together.

  • Choose one or several files from your device
  • Selected files are saved together as a single attachment entry
  • No separate record is needed for every file
04

Upload and Save

Submit the form and let the system store your files.

  • Submit the form to upload the files
  • Original names, types and combined file size are recorded
  • The attachment appears on the list page
05

View, Download, Update or Remove

Open any saved attachment and manage it whenever needed.

  • Preview an individual file when the browser supports it
  • Download any file separately, or all files as one ZIP package
  • Change a label, add more files, or remove selected files
  • Delete an entire attachment entry when no longer required
