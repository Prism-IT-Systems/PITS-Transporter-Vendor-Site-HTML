Simplify Manager Fund Tracking

The Manager Balance Management Module helps transport and fleet businesses see how much money has been provided to each manager, how much has been paid out, and how much remains available. Instead of calculating balances manually, users can review a clear summary and transaction history in one place. The module works together with the Expense Book and Payment Management features, making it easier for accounts staff and managers to understand day-to-day fund movement.

Manager Balance Module Features

Manager-Wise Balance Overview

View the summary for individual managers in one list instead of checking separate registers.

Advances Received

See the total funds or advances recorded for a manager.

Payments Made

See the total system-recorded payments created by that manager.

Automatic Remaining Balance

The balance is calculated as total advances received minus total recorded payments.

Individual Transaction Ledger

Open a manager's ledger to review individual credits, debits, and descriptions.

Running Balance

The Manager Balances page requires permission, and regular managers are restricted to their own ledger.

Expense Book Connection

Step-by-Step Workflow

How Does the Manager Balance Module Work?

Five steps take you from recording funds to reviewing the available balance.

01

Record Funds Provided to a Manager

When the business provides money to a manager for daily work, the relevant fund or advance entry is recorded through the Expense Book workflow.

  • The manager's available funds increase when an advance is recorded
  • The older standalone Manager Advances screens redirect to Expense Book in the current project
02

Record Payments Made by the Manager

As the manager makes vendor or driver payments in the system, those recorded payments count toward the money used by that manager.

  • Each payment reduces the remaining float balance
03

Check the Balance Summary

Open Manager Balances to see managers and their total advances received, payments made, and remaining balance.

  • Choose a manager using the available manager filter
  • Select Search to find their row
04

Open the Manager Ledger

Select View Ledger beside a manager to see the transaction history.

  • The ledger displays the date, transaction type and description
  • It shows money received (credit), money paid (debit), and running balance after each transaction
05

Review Available Funds

The current balance helps the accounts team know how much money is still available to a manager.

  • The system can also show a warning when a proposed payment would exceed the available funds
  • This is a warning rather than an automatic guarantee that the payment cannot proceed
