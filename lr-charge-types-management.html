Practical Example: Calculating LR Charges

Sample Lorry Receipt Charges
Suppose a company is preparing a Lorry Receipt with the following charges. The charge names and amounts below are only examples.
Charge Type Calculation Amount
Freight Add ₹12,000
Hamali Add ₹600
Other Add ₹250

The system uses the selected charge or deduction type to calculate the LR amount. In this example, ₹12,000 + ₹600 + ₹250 − ₹3,000 = ₹9,850.

Complete solution

Key Features

Everything you need to define, order, apply and maintain LR charge types.

Custom Charge Types

Create charge names that match the transport business, such as Freight, Hamali, Loading, Surcharge or Other.

Charge Codes

Add an optional short code to identify a charge type. For example, FRT for Freight.

Additions and Deductions

Mark a charge type as a deduction to subtract its amount from an LR total; leave it unchecked for additional charges.

Display Order

Use Sort Order to organize how charge types appear, making frequently used options easier to find.

Active and Inactive Status

Control whether a charge type is available for creating new Lorry Receipt entries, without deleting the record.

Lorry Receipt Integration

Use active charge types during LR creation and editing to build the freight and other charge breakdown.

Party-Specific Default Rates

The system supports party charge rates linked to charge types, allowing default charge amounts to be stored for individual parties where configured.

View and Sort Records

View charge names, codes, order and status. Sort the list by name or use the default display order.

Edit Charge Types

Update existing settings when business billing practices change.

Trash and Restore

Move a charge type to Trash instead of permanently removing it immediately, and restore it if needed.

Permission-Based Access

Separate permissions are checked for viewing, creating, editing and deleting charge types.

Activity History

Creation, updates, deletion and restoration are logged; authorized users can access the Activity Log.

Step-by-Step Workflow

How Does the Module Work?

Six simple steps take you from opening LR Charge Types to using them in a Lorry Receipt.

01

Open LR Charge Types

Open the LR Charge Types section to see the saved charge names. You can view the charge code, display order, status and available record actions.

02

Create a Charge Type

Click Add Charge Type. Enter a clear name such as Freight, Hamali or Loading Charge. You may also enter a short code so the charge can be recognized easily.

03

Choose Charge or Deduction

Leave Deduction unchecked for a normal charge that increases the LR total. Select Deduction for an item such as Less Advance that should be subtracted from the total.

04

Set Order and Status

Enter a Sort Order to decide the position of the charge type in the list. Set the status to Active when the type should be available for new Lorry Receipts, or Inactive when it should not be used for new entries.

05

Save and Use in a Lorry Receipt

Save the charge type. When creating or editing a Lorry Receipt, active charge types are available for entering amounts. The LR calculates the total using added charges and applicable deductions.

06

Maintain Charge Types

When required, edit the name, code, order, deduction setting or status. Unneeded charge types can be moved to Trash and restored later by authorized users.

Introduction

Reusable LR Charge Types

Every Lorry Receipt (LR) may include more than just freight. There can be handling charges, additional service charges, or deductions such as an advance already paid. The LR Charge Types Module helps transport businesses define these charge names once and use them consistently while preparing Lorry Receipts. Users can create charge types, decide whether a charge increases or reduces the total, manage their display order, and keep the list up to date without changing each LR individually.

  • Create charge types
  • Decide whether a charge increases or reduces the total
  • Manage their display order
  • Keep the list up to date without changing each LR individually
  • Apply charge types consistently across all Lorry Receipts
