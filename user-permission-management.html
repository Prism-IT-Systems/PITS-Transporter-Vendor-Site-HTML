Key Module Features

Control User Access, Assign Roles & Manage Module Permissions in One Place.

Role-Based Access

Manage access by role rather than setting the same rules separately for each employee. Available user roles include Admin, Accountant, Maintenance and Manager.

Module-Wise Permissions

Permissions are organized by software modules, making it easier to control access to areas such as fleet, maintenance, business, documents and administration, depending on the permissions configured in the system.

Action-Level Controls

Specify whether a role may view, create, edit or delete records where those actions are available. For example, a role can be allowed to view a module without being allowed to change its data.

Search Modules Quickly

Use the module search box to find the exact area whose permissions need to be changed, instead of manually checking every category.

Grouped Permission Categories

Modules are arranged into categories such as Overview, Fleet Management, Maintenance, Business, Lorry Receipts, Documents and Admin to make navigation easier.

Select Multiple Permissions

Use the available row-level or section-level selection controls to update several related options more quickly.

Show Assigned Modules

The screen includes an option for hiding unassigned modules so the administrator can focus on modules that already have selected permissions.

Review Existing Access

When switching roles, the screen loads their currently assigned permissions. This helps administrators understand which activities the role is already allowed to perform.

Save Role Permission Changes

After changes are reviewed, Save Changes updates the selected role permissions. Dashboard access is included by the permission-saving logic.

User Account and Role Updates

Authorized staff can create users, update user details, and change a user’s assigned role through the separate User Management screens.

Access Protection

Protected routes check permissions before allowing actions. If a non-admin user lacks the required permission, access is denied.

Step-by-Step Workflow

How Does the Module Work?

Follow six simple steps to assign a role, choose the permitted modules and actions, and confirm that access is enforced.

01

Add a User and Assign a Role

From User Management, an authorized person creates an employee account.

  • Enter a name, email and password
  • Assign a role such as Admin, Accountant, Maintenance or Manager
02

Open User & Permission Management

Go to the permissions page.

  • Decide what a particular role can do in the system
03

Select the Role

Choose Accountant, Maintenance or Manager.

  • The page loads the permissions currently assigned to that role
  • The Admin role has full access through the application’s permission checks
04

Choose Modules and Actions

Find the required module using the search field or module categories.

  • Enable or disable available actions such as View, Create, Edit and Delete
  • Options depend on what is offered for that module
05

Review and Save

Check the selected options and click Save Changes.

  • The chosen permissions are saved for the role
  • Users assigned to that role receive its access rules
06

Check User Access

When a user opens a protected module or action, the system checks the user’s role and permissions.

  • Users without the required permission cannot complete that protected action

Access Protection

Protected routes check permissions before allowing actions. If a non-admin user lacks the required permission, access is denied.
