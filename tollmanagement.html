Toll Management Module

Transport and fleet businesses often need to check toll charges for many vehicles. When FASTag statements and manually recorded toll payments are kept separately, finding an individual trip or checking total toll expenses can take time.

The Toll Management Module brings toll records into one place. Users can enter toll transactions manually, import FASTag statements, connect transactions to fleet vehicles, search toll history and export transaction details for accounts and reporting.

Key Module Features

Everything You Need for Toll Management

4.1

Manual Toll Entry

Record a toll transaction for a chosen vehicle and Toll vendor, including the transaction date and amount.

4.2

Debit and Credit Transactions

Record debit charges and credit adjustments separately. The listing can summarize debits, credits and net amounts.

4.3

FASTag Statement Import

Import transactions from supported statement files such as XLS, XLSX, CSV, TXT and HTML, subject to the statement parser's supported layout.

4.4

Flexible Column Mapping

Map bank or FASTag statement column names to the system fields, making imports easier when different providers use different headings.

4.5

Vehicle-Wise Toll Records

Associate a toll payment with the relevant vehicle and look up its toll transaction history.

4.6

Unlinked Vehicle Review

Keep imported records when a vehicle registration number has not yet matched a fleet vehicle, and review these records separately.

4.7

Link Matching Vehicles

Run a matching process to link unlinked toll transactions to existing vehicles when their vehicle numbers match.

4.8

Toll Vendor Details

Associate toll entries with a Toll-type vendor to keep related transactions organized.

4.9

FASTag Account and Plaza Information

Store FASTag account details, plaza codes and transaction descriptions where available.

4.10

Transaction References and Source

Retain transaction IDs, activity information and whether entries were imported or manually recorded where applicable.

4.11

Duplicate Checking

The manual create/edit process checks for an existing matching transaction and can show a duplicate warning.

4.12

Search, Filters and Sorting

Find records using vehicle, vendor, tag account, source, unlinked status and date filters, and sort transaction listings.

4.13

Toll Expense Summary

For filtered records, review transaction count and debit, credit and net totals.

4.14

CSV Reports

Export filtered toll transactions to a CSV file containing vehicle, vendor, FASTag, plaza and transaction amounts.

4.15

Edit, View and Delete

Authorized users can open transaction details and update or delete toll records according to their permissions.

Step by Step

How Does the Toll Management Module Work?

01

Step 1: Open Toll Management

Open the Toll Management section to view saved transactions.

  • You can review the listing, search for a vehicle or choose to add a new toll entry.
Step 01
02

Step 2: Add a Toll Transaction

Select the vehicle and Toll-type vendor.

  • Enter the transaction date, amount and whether it is a debit or credit.
  • Add a FASTag account number, toll plaza code, description or remarks if available.
Step 02
03

Step 3: Save and Review

Save the transaction and open its details whenever required.

  • Authorized users can edit or delete a manually managed record.
Step 03
04

Step 4: Import a FASTag Statement

Instead of adding many records individually, upload a supported FASTag statement.

  • The system reads the file and presents a column-mapping step to match statement fields to toll fields.
Step 04
05

Step 5: Match and Import Records

Review the suggested column mapping and process the import.

  • The system imports supported rows and attempts to associate the vehicle registration numbers with the vehicles already in your fleet.
Step 05
06

Step 6: Review Unlinked Entries

Transactions that do not match an existing vehicle can remain visible as unlinked.

  • Once the vehicle record or registration number is corrected, use the available linking action to connect matching transactions.
Step 06
07

Step 7: Filter and Export

Filter by vehicle, vendor, FASTag account, source, unlinked status or transaction dates.

  • Download the selected records as a CSV report for Excel.
