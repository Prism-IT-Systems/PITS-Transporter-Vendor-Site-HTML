Step-by-Step Workflow

How Does the User Management Module Work?

Follow six simple steps to open the user list, create accounts, set secure passwords and keep user information up to date.

01

Open the Users List

Open Users from the admin menu.

  • The page displays names, email addresses, assigned roles and available actions
  • Search by user name or email when you need a specific account
02

Create a New User

Click Create New User (or the available add-user option).

  • Enter Full Name, Email Address, Assigned Role, Password and Confirm Password
  • Each email address must be unique
03

Choose a User Role

Select Admin, Accountant, Maintenance or Manager, depending on the person’s responsibilities.

  • A role determines which permissions the application can grant
  • Detailed module-wise permission setup is handled in User Permissions
04

Set a Secure Password

Enter a password of at least eight characters.

  • Include uppercase and lowercase letters, a number and a symbol
  • Re-enter the same password in Confirm Password
  • Select Register User
05

View and Update a User

Open a user record to view account information.

  • Choose Edit to change the name, email or role
  • To change the password, enter and confirm a new one; otherwise leave the password fields blank
06

Search and Manage Users

Use name or email search to locate accounts.

  • Sort the list by name and browse pages of results
  • Authorized staff can view, edit or delete users using the available actions
