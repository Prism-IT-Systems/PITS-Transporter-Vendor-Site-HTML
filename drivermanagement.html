Driver Management Module

Managing driver information across multiple trucks can be difficult when contact details, driving licence records and documents are kept in separate registers. The Driver Management Module helps businesses maintain driver profiles and access the information they need from one place.

Users can add drivers, link drivers with vehicles, store identity and licence documents, update details and review related salary and payment information. It is designed to make day-to-day driver record management easier for transport and fleet businesses.

Key Module Features

Everything You Need for Driver Management

4.1

Driver Profile Management

Maintain essential information such as name, date of birth, phone number and address in a single driver profile. Instead of searching multiple files, users can open the saved driver record whenever they need it.

4.2

Driving Licence Details

Record the driving licence number, issue date and expiry date for reference. Users can update these fields when licence information changes. The reviewed code stores expiry dates; automated expiry notifications are not confirmed here.

4.3

Vehicle Assignment

Connect a driver to a vehicle so the business can see the current vehicle associated with that person. The system prevents the same vehicle from remaining the current link on multiple driver profiles when reassigned.

4.4

Driver Document Storage

Store Aadhaar, PAN, Driving Licence and other supporting documents with the driver record. Multiple attached files can be viewed or downloaded according to the available document controls and permissions.

4.5

Monthly Pay Details

Enter an optional monthly pay amount when creating or updating the driver profile. This provides a useful salary reference and supports the wider payroll-related functions present in the application.

4.6

Active and Inactive Status

Mark drivers as Active or Inactive to reflect their current status in the company. This helps maintain records for both current and former drivers.

4.7

Driver List, Search and Sorting

View a paginated list of drivers. Search by driver name or linked vehicle number and sort by name or recent records to find details faster.

4.8

Edit and Manage Records

Authorized users can correct contact information, licence details, vehicle assignment, monthly pay and documents. The system also supports deletion where the user has permission.

4.9

Driver Detail View

Open an individual driver record to see saved profile details, linked truck, attached documents, recent payment information, outstanding payable amount and salary-rate history where records exist.

4.10

Driver Salary and Truck-Rate History

The wider application includes driver payroll, truck-rate records and assignment history. These support reviewing driver rates and payroll-related records; individual salary calculations depend on the dedicated payroll workflow.

4.11

Driver Payments

The driver profile can display recent related payments and outstanding amounts. Payment management follows the separate payment and payroll features of the application.

4.12

Secure Document Access

Available controls allow saved driver documents to be viewed, downloaded and managed using protected document links, helping users retrieve files from the relevant profile.

Step by Step

How Does the Driver Management Module Work?

01

Step 1: Add a New Driver

Open the Driver Management section and select Add New Driver.

  • Enter the driver's name, date of birth, contact number and address.
  • Add driving licence details and the monthly pay amount when applicable.
02

Step 2: Link a Vehicle

Select the vehicle currently assigned to the driver, if any.

  • This keeps the driver and truck connected in the system.
  • The current vehicle link can be updated if the driver changes trucks.
03

Step 3: Add Driver Documents

Choose document types such as Aadhaar, PAN, Driving Licence or Other, enter the relevant document number where required, and attach scans or images.

  • Supported driver document uploads include PDF and common image formats.
04

Step 4: Save the Driver Profile

Review the information and select Create Driver.

  • The new driver becomes available in the Driver List and can be opened for a complete view.
05

Step 5: View and Update Records

Open a driver profile to review saved details and documents.

  • Authorized users can edit driver information, change vehicle assignment, update salary details and manage document attachments.
06

Step 6: Find Driver Information

Search the Driver List by driver name or linked vehicle number.

  • Open the matching profile to view its details, related payment information and salary-rate history.
