Audit & Control Features

Everything Your Activity Log Needs

A comprehensive audit tracking suite designed to provide complete operational transparency, maintain compliance records, and trace every system event.

Central Activity History

View recorded activities from supported modules in one place, without opening each business record separately.

User-Wise Activity Tracking

See the name of the person associated with a recorded action, and search by user name to check relevant activities.

Module-Wise Filtering

Choose a module to focus on its actions. Modules available in the filter are based on activity records already stored in the system.

Action Tracking

Identify whether an activity was a creation, update, deletion, restoration, or print event, where recorded by the related module.

Date and Time History

Review exactly when an activity was recorded. Filter by dates to check activities during a specific operational period.

Record Identification

Check which specific record was involved, such as an LR number, party name, or charge type when a record label is available.

Activity Descriptions

Read an easy-to-follow description of the logged event to understand what happened without needing technical codes.

Expandable Change Information

Open “View changes” when extra details are present to review exact field modifications without overcrowding the main table.

User Name Suggestions

As users search by name, the interface can suggest matching user names dynamically from existing log records.

Search and Reset

Combine filters for a focused review and reset them quickly with one click to return to the full unsegmented history.

Paginated Activity List

Review records in manageable 25-item pages rather than dealing with an overwhelming, slow-loading continuous list.

Permission-Based Access

Only users authorized to view activity logs can access the page, keeping administrative activity information appropriately restricted.

Step-by-Step Workflow

How Does the Activity Log Module Work?

The module provides an intuitive five-step workflow that helps managers and administrators monitor software activities without complex query tools.

01

Open Activity Log

An authorized user opens Activity Log from the application menu. The most recent recorded activities appear first.

  • Access Activity Log directly from the main sidebar menu
  • Protected by administrative Activity Log authorization
  • Latest actions presented immediately at the top
Workflow Phase 01
02

Review the Activity List

Each activity shows when it happened, the user involved, the module, the action taken, the related record, and a short explanation.

  • Inspect timestamp, user, module, and record ID
  • Common actions: Created, Updated, Deleted, Restored, Printed
  • Clear human-readable event descriptions
Workflow Phase 02
03

Apply Filters

Select a module and action, type a user name, or choose a From and To date. Click Search to see matching activities, or Reset to clear.

  • Filter by specific business module and action category
  • Search user name with automatic predictive suggestions
  • Date range boundaries for fast historical investigations
Workflow Phase 03
04

View Change Details

If the activity contains additional saved change information, click “View changes” to expand and review field-level before/after data.

  • Click "View changes" inline button on any record
  • Inspect altered quantities, weights, rates, or status values
  • Keep the main table clean with expandable accordions
Workflow Phase 04
05

Check Older Activity

Browse the activity history using pagination. The list displays 25 records per page, making larger histories easier to review.

  • Page through large databases without performance lag
  • 25 records per page standard pagination
  • Fast navigation between past audit milestones
Workflow Phase 05

Ensure complete accountability with tamper-evident activity logging, encrypted event archives, and role-based administrative visibility.
