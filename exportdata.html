Key Module Features

Key Module Features

Everything the Export Data feature offers for downloading business records as CSV files.

Diesel Logs Export

Download diesel purchase entries with purchase date, vehicle, vendor, company, liters, rate, amount, odometer, slip number and notes.

Diesel Date Range Filter

Choose a starting and ending date to export diesel purchases for a selected period. The date-range filter works when both dates are provided.

Vehicle-Wise Diesel Export

Choose a particular vehicle to download diesel entries linked to that vehicle.

Vendor-Wise Diesel Export

Choose a supplier to download diesel purchase records linked to that vendor.

Vehicle Data Export

Download active vehicle records with vehicle number, owner, make, model, year, chassis number, engine number and notes.

Driver Data Export

Download active driver information including name, date of birth, licence number, licence issue and expiry dates, Aadhaar number, phone and address.

Vendor Data Export

Download active vendor records with name, contact person, phone, email, address and GST number.

CSV File Format

Exported files use the CSV format, which can be opened in Excel or other compatible spreadsheet applications.

Clear Column Headings

Each CSV includes headings so users can understand what information is stored in each column.

Export Permission Control

Only users with the Reports Export permission can use these export actions.

Ready-to-Use Filenames

Downloaded files use recognizable names such as diesel_logs.csv, vehicles.csv, drivers.csv and vendors.csv.

Excel-Friendly Record Keeping

Use exports for internal verification, spreadsheet analysis or preparing business reports without manually copying saved records.

Step-by-Step Workflow

How Does Export Data Work?

Five steps take you from choosing the data you need to using the exported records.

01

Choose the Data to Export

Open the relevant export option and select the records you need.

  • Diesel Logs
  • Vehicles
  • Drivers
  • Vendors
02

Apply Available Filters

For Diesel Logs, choose a date range, vehicle or vendor if you want specific records.

  • Other export options in this feature download active records without those diesel-specific filters
03

Start the Download

Select the export option to generate a CSV file containing the available columns for that record type.

  • Files use recognizable names such as diesel_logs.csv, vehicles.csv, drivers.csv and vendors.csv
04

Open and Review the File

Open the downloaded CSV file in Excel or another spreadsheet application.

  • Each record appears in a separate row
  • Headings identify the data in each column
05

Use the Exported Records

Put the downloaded records to work for your team.

  • Review diesel expenses
  • Check vehicle or driver information
  • Verify vendor details
  • Share the file with an authorized team member
