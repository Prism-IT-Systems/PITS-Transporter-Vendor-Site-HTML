Module Features

Office Document Module Features

Everything the Office Document module offers for storing, finding and managing office records.

Centralized Office Document Records

Keep important office document information together instead of storing details in separate files or registers.

Flexible Document Types

Organize records by document type. Users can select an existing type or provide a type name according to the form's available options; the system does not impose a fixed list of office document categories.

Document Number Management

Record a document reference number to make identification easier. The system checks that the same document number is not already assigned to another office document.

Validity Date Records

Maintain Validity From and Validity To dates for documents that have a defined validity period. These dates make it easier to review when a document is valid.

Office Vendor Association

Link an office document to an available active office vendor when the document relates to a supplier or service provider.

Document Amount Recording

Add an amount to record a document-related cost, fee or charge when applicable.

Digital File Upload

Store PDF or image attachments with a saved document, helping users access a digital copy instead of searching paper files.

Secure File View and Download

Authorized users can preview attached files in the browser or download them. Document links use time-limited access tokens.

Search and Document Filters

Find entries using their document type or document number. The listing also supports payment-status filtering and vendor-name sorting.

Document Detail View

Open a record to review its document type, number, validity dates, linked vendor, amount and available attachment.

Edit and Replace Attachments

Authorized users can update document details and upload a replacement document file when information changes.

Delete Document Records

Users with delete permission can remove office document records, including their stored attachment.

Payment-Related Tracking

Office document records support payment allocations and the listing can be filtered by payment status. Actual payment entry actions depend on the separate payment workflow.

Role-Based Access

Viewing, creating, editing and deleting office document records are controlled by user permissions.

Step-by-Step Workflow

How Does the Office Document Module Work?

Six steps take you from opening Office Documents to searching and updating saved records.

01

Open Office Documents

Open the Office Documents section to see previously saved records.

  • You can review the listing
  • Or choose to add a new document
02

Enter Document Information

Select or enter the document type, add a document number if available, and enter Validity From and Validity To dates where relevant.

  • Document type can be selected or entered
  • Document number is optional
  • Validity dates are entered where relevant
03

Link a Vendor and Amount

Choose the related office vendor and enter the document-related amount if applicable.

  • These fields can be left empty when they do not apply
04

Upload a Digital Copy

Attach a PDF, JPG, JPEG or PNG file to the document record.

  • The system accepts files up to 10 MB
05

Save and View

Save the document.

  • Open the saved record to view its details
  • Preview the attachment or download the file
06

Search, Filter and Update

Find saved records using document type or number, and use available payment-status filters.

  • Authorized users can edit document details
  • Replace attachments or delete records
