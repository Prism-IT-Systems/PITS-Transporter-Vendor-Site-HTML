Global Search Module

Finding a particular vehicle, vendor, diesel purchase, repair, or document can take time when business information is stored in different modules. Global Search makes it easier to find relevant records from one place. Users can enter a name, number, or keyword, apply filters, and open matching records without checking each module separately.

The system also offers a separate quick module search to help users navigate directly to application sections such as Vehicles, Drivers, Diesel, Repairs, and Reports.

Find a Truck's Diesel Purchase

Suppose an accounts employee needs to find fuel purchases for truck GJ 05 AB 1234. They open Global Search, select that vehicle, choose Diesel in the Component filter and enter a date range. The results show matching diesel records for the selected conditions. The employee opens the relevant result to check its available purchase details. Key Module Features

Everything You Need for Global Search

4.1

Search Across Business Records

Search from one place across the record types configured for the application, including vehicle, vendor, driver, diesel, maintenance, battery, tyre, and document-related information.

4.2

Name, Number and Keyword Search

Look for records using recognizable information such as vehicle registration numbers, vendor names, and saved description fields. Search matches depend on the fields available for each record type.

4.3

Vehicle Filter

Select a particular vehicle to narrow supported results related to that vehicle.

4.4

Vendor Filter

Select a diesel or service vendor to narrow records linked to that supplier. Some record types use separate vendor data and may not appear with this filter.

4.5

Date Range Filter

Use Date From and Date To to search supported records with relevant dates. Date filtering applies only to record types for which date fields are configured.

4.6

Component Filter

Limit results to supported groups: Diesel, Toll, Service, Tyre, or Battery.

4.7

Clear Search Results

Reset the entered conditions whenever you want to search for a different record.

4.8

Useful Result Information

Results identify their record type and can show extra context such as a vehicle number, vendor, owner or contact person.

4.9

Open Matching Records

Use a result link to navigate to its corresponding module page, where a linked detail route is available.

4.10

Latest-First Results and Pagination

Matching records are arranged with recently created records first, with results shown in manageable pages.

4.11

Quick Module Navigation

Use the separate "Search module..." box to find and open application sections quickly, instead of navigating through menus.

4.12

Access-Based Module Links

Quick module search lists sections according to the signed-in user's available menu permissions.
