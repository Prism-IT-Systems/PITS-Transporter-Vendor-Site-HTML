Module Features

Expense Book Module Features

Everything the Expense Book offers for recording, reviewing and organizing daily company payments.

Daily Expense Book

Maintain a separate expense sheet for each company and date, with the option to revisit past or upcoming dates.

Multiple Expense Entries

Record several expenses in one sheet using Add Row or Add Another Row instead of saving each payment separately.

Company-Wise Records

Choose the relevant firm so daily spending stays associated with the correct company.

Vendor Payments

Record payments for ordinary, reefer or office vendors. Applicable amounts are allocated to unpaid vendor invoices in oldest-first order.

Driver Pay

Select a driver and choose Driver Pay to record a payment associated with that driver.

Vehicle Expenses

Record an expense against a vehicle, or select a driver for a vehicle-related cost. Where supported, the driver's linked vehicle can be identified for that day.

Manager Daily Expenses and Salary

Choose a manager and specify whether the payment is a Daily Expense or Salary. Daily Expense entries also sync with manager advance/day-book records.

Payment Methods and References

Enter the supported payment method and an optional transaction or cheque reference for easier verification.

Expense Notes

Add a note to individual expense rows and separate day notes for the complete sheet.

Automatic Daily Total

Review the total expense amount calculated from the amounts entered in the daily sheet.

Edit and Delete Controls

Staff with appropriate permissions can update existing sheets; authorized users can delete a book when needed.

Linked Payment Records

Applicable vendor and driver payment entries are connected to payment records rather than remaining only as unlinked notes.

Step-by-Step Workflow

How Does the Expense Book Module Work?

Six steps take you from selecting a company and date to saving and reviewing linked payments.

01

Select Company and Date

Open Expense Book and select the company (firm) and the day for which you want to enter expenses.

  • Use Previous and Next to move between dates
  • The system keeps one expense book per company per date
  • Existing entries for that day can be reopened instead of creating a duplicate sheet
02

Add an Expense Row

Click Add Row and choose the payee or relevant vehicle.

  • Payee can be a vendor, reefer vendor, office vendor, driver or manager
  • For vehicle-only spending, select the vehicle
  • Add more rows to record multiple payments in the same daily sheet
03

Enter Purpose and Payment Details

Enter the expense amount, payment method, reference and notes.

  • For a driver, choose Driver Pay or Vehicle Expense
  • For a manager, choose Daily Expense or Salary
  • Select a vehicle when required for vehicle-related expenses
04

Review the Daily Total

The expense book shows the combined amount of the recorded rows.

  • Review every entry
  • Add optional day notes to describe the day's spending
05

Save or Update the Book

Click Save Expense Book. The entries are stored under the selected company and date.

  • Authorized users can later reopen the day, change rows or remove entries
  • Existing book company and date cannot be changed
06

Review Linked Payments

For vendor payments, the system links amounts to the oldest unpaid invoices first, where eligible invoices exist.

  • Driver Pay rows create or update driver payment records
  • Manager Daily Expense rows are linked to manager advance/day-book records
  • If a vendor payment exceeds available unpaid invoices, the system asks the user to correct it before saving
